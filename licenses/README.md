# Included license material

This directory accompanies Paneleo's source, installer, and portable build.

- `AGPL-3.0.txt`: Paneleo, PyMuPDF, and MuPDF open-source license text.
- `GPL-3.0.txt`: GPL version 3 text referenced by LGPL version 3 and Qt licensing options.
- `LGPL-3.0.txt`: Qt/PySide open-source license text used by this distribution.
- `LGPL-2.1.txt`: license text used by some Chromium third-party components.
- `Apache-2.0.txt`: Apache License 2.0 used by OpenSSL, PyInstaller runtime hooks, and some Chromium components.
- `Python-3.12.10.txt`: exact license and notices shipped with CPython 3.12.10.
- `OpenSSL-3.0.16.txt`: exact license text from OpenSSL 3.0.16.
- `PyInstaller-6.22.2.txt`: exact PyInstaller license and bootloader exception from the installed package.
- `Inno-Setup-7.1.0.txt`: exact Inno Setup license notice.
- `Qt-WebEngine-6.11.2-Third-Party-Components.html` and `qt-webengine-notices/`: offline copies of Qt's index and 126 component-by-component Qt WebEngine/Chromium copyright and license notice pages for Qt 6.11.2.

See `THIRD_PARTY_NOTICES.md` for versions, copyright summaries, and how each component is used.
