# Contributing

Bug reports, feature requests, and pull requests are welcome.

- Check existing issues before opening a new one.
- Open an issue before making a large or user-visible change.
- Keep changes focused and avoid unrelated refactoring.
- Follow the setup instructions in [docs/BUILDING.md](docs/BUILDING.md).
- Run `.venv\Scripts\python.exe -m pytest -q` before opening a pull request.
- Do not include comics, account data, browser profiles, logs, or other private files.

Paneleo is currently developed and tested on 64-bit Windows.
