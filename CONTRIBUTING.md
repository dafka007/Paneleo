# Contributing

Bug reports, feature requests, and focused pull requests are welcome.

- Search existing issues before opening a new one.
- Open an issue first for significant changes or user-visible behavior changes.
- Keep changes focused and avoid unrelated refactoring.
- Run `TEST.bat` before submitting a pull request.
- Do not include comic files, account data, browser profiles, logs, or other private data.

Paneleo is currently developed and tested on Windows x64.
